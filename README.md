# Stokes Valley Tennis Club

The website for Stokes Valley Tennis Club, built with Nuxt 4, Vue 3 and
TypeScript.

## Setup

Make sure to install dependencies:

```bash
npm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```

## Production

Build the application for production:

```bash
npm run build
```

Locally preview production build:

```bash
npm run preview
```

Set `NUXT_PUBLIC_SITE_URL` to the production URL when deploying so canonical
URLs and the sitemap use the correct domain.
